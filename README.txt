OCDE Timesheet Calculator - responsive website

Deploy this directory to Vercel as a static Other project (no build command or framework needed).

The HTML uses no external scripts, backend or database. It saves entries in the browser localStorage on that device.

Open index.html in a normal browser to test. Desktop keeps the paper table, phone switches to stacked shift cards; print/PDF remains landscape table.

This is an independent calculation aid, not an official OCDE form.
