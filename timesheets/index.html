    Saved Pay Periods & History

    Each Save creates a separate dated snapshot, even for the same pay period. Reopening a snapshot makes an editable working copy; your prior saved version remains unchanged. Download backups regularly and keep PDFs in an OCDE-approved location. Browser storage can be cleared or lost and is not an official audit archive.

    Feedback for ShiftLedger

    Do not include employee names, IDs, timesheets, student information, or other sensitive details. Feedback is NOT sent to any server by this app.
    How calculations work: Classify each shift before generating separate PDFs. Extra Hours use minutes ÷ 60 rounded to 2 decimals for each shift (50 minutes = 0.83). Overtime uses regular hours:minutes (1 hour 45 minutes = 1:45) without decimal conversion. The categories have separate totals. Enter times in the correct AM/PM using the time picker. End time must be later than start time on the same day. Entries are saved only in this browser on this device. This is an unofficial calculation aid; the resulting printout is not an OCDE-issued payroll form.
